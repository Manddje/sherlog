Deploy in Intune

  1. Devices → Scripts and remediations → Create
  2. Paste as the Detection script; leave the remediation script empty
  3. 64-bit PowerShell: Yes · logged-on credentials: No
  4. Assign to a device group, or pick a device → Run remediation
